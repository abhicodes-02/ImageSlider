# Image Slider 🎞️

This is a simple and responsive Image Slider using HTML, CSS, and JavaScript.

## 🚀 How to Run the App

1. Download or clone this repository.
2. Extract the ZIP file if downloaded.
3. Open `index.html` in any modern browser (Chrome, Firefox, Edge, etc.)

## 📁 Project Structure

- `index.html` – Main file that renders the image slider
- `index.css` – Styles for layout and transition
- `script.js` – JavaScript logic for sliding functionality

## ✨ Features

- Automatic and manual slide control
- Responsive design
- Smooth fade/slide transition between images

## 📝 Notes

- No external libraries required.
- Works fully offline.
